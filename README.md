# habby landing page

Mobile-first landing page for [habby](https://habby-org.github.io/).

The site is a dependency-free static page and deploys automatically to GitHub Pages whenever
`main` is updated.

## Local preview

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Store links

The store controls currently show a coming-soon message. Add the App Store and Google Play URLs to
`index.html` after each listing is published.
